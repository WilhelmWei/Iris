AI 电脑体检 · 远程体检
========================

这是什么
--------
一个电脑体检小工具。它会检查你电脑里装了什么、开机启动了什么、有没有卸载不干净的残留、
安全设置是否正常，然后生成一份报告。你把报告发给把工具给你的人，他用 AI 研判后，
会把一份中文体检报告发回给你：哪些没问题、哪些建议处理、为什么。

怎么用（3 步）
--------------
1. 把压缩包完整解压（不要在压缩包里直接双击）
2. 双击 start.bat。弹出"是否允许此应用对你的设备进行更改"时点"是"
   （需要管理员权限才能检查驱动、蓝屏记录等；点"否"也能运行，只是结果不完整）
   如果 Windows 提示"无法验证发布者"或"Windows 已保护你的电脑"，点"更多信息"→"仍要运行"
3. 大约 1–2 分钟后会弹出一个对话框，告诉你报告保存在哪；点"确定"后会打开报告所在的文件夹。
   把桌面上的 pcdoctor-report-时间.json 发给把工具给你的人

安全吗
------
· 只读：不修改任何设置、不删除任何文件、不安装任何东西。唯一写入的是桌面上那份报告
· 不联网：检查过程完全在你电脑上进行，报告发不发、发给谁，由你决定
· 不常驻：检查完就结束，不会留在后台，也不会开机启动
· 代码公开：start.bat 和两个 .ps1 文件都是纯文本，用记事本就能打开看每一行在做什么

报告里有什么
------------
· 系统版本、电脑型号、CPU、内存、各盘空间
· 已装软件、正在运行的程序、开机自启动、服务、计划任务、驱动的名字和路径
· 安全设置（Defender、防火墙、UAC），最近的蓝屏和程序崩溃记录
· 网络设置（系统代理、hosts、DNS 服务器地址），浏览器扩展的名字
· 几个常见文件夹的大小（只算大小，不看内容）

已经去掉：你的用户名、计算机名、邮箱地址（换成 [用户] 这样的占位符）
不会包含：任何文档、照片、聊天记录、浏览记录、密码，本机 IP、MAC 地址、Wi-Fi 名称
请注意：文件夹路径里的名字会保留（比如 D:\项目\毕业设计）。介意的话可以先用记事本打开报告看一看。

查病毒呢
--------
查病毒交给 Windows 自带的 Microsoft Defender，这个工具只读取它的检测结果，不修改任何安全设置。
我们相信用好已有的强大工具，比重复造一个杀毒引擎更可靠。

怎么确认文件没被别人改过
------------------------
只从把工具给你的人那里、或者项目的 GitHub 页面获取，不要用别人转发的版本。
想核对的话，SHA256SUMS.txt 里是每个文件的校验码，可以在 PowerShell 里运行：
    Get-FileHash .\start.bat
把结果和 SHA256SUMS.txt 里对应的那行比较，一致就说明文件没被改过。
