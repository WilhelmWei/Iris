# 「家人的电脑」详细设计稿（方案 A + 方案 C）

> 状态：**设计稿，等作者看过、同意后才写代码**。2026-11-01。
> 原则：用户体验至上；不常驻、不弹窗；每一步可撤销；服务器看不到任何人的报告。

## 1. 一句话

帮忙的人（下文叫"顾问"，例如你）和被帮的人（下文叫"家人"，例如爸妈、朋友）**只需要绑定一次**；之后家人每次体检，报告自动加密同步给顾问；顾问在自己的 Iris 里勾好要处理的项、写一句话；家人下次打开 Iris，看到「Wilhelm 帮你准备好了 3 项，点一下就好」，确认后执行，结果自动回给顾问。

方案 C 是前提：AI 问卷和性格先把大部分"看不懂、不敢点"的问题在家人自己的电脑上解决掉，需要顾问出手的只剩疑难杂症。

## 2. 谁、在什么时候用

| 场景 | 顾问在哪 | 家人电脑上有没有 Iris |
| --- | --- | --- |
| 回家给爸妈装电脑 | 就在家人电脑旁边 | 顾问现场装 |
| 朋友在微信里说"电脑好卡" | 远程 | 多半没有 |
| 已经绑定过，家人又说卡 | 远程 | 有 |

设计要让这三种都顺手，而**家人一侧的操作要尽量是零**。

## 3. 绑定：一次就好

### 3.1 顾问一侧

「家人的电脑」页 → 「添加一台家人的电脑」→ 起个名字（"妈妈的笔记本"）→ Iris 生成一份**邀请**，同时给出两种形式：

- **邀请链接**：`https://<下载页域名>/f#…`（`#` 后面的部分不会发给服务器）
- **邀请口令**：一段可以整段复制的文字，形如
  `【Iris】Wilhelm 想帮你照看这台电脑。复制这整段文字，打开 Iris 就好 ✦IRIS:7Q4K…✦`

界面上只有一个按钮「复制，发到微信」，复制的内容是"口令 + 链接"合在一起的一段话，顾问直接粘贴发给家人。

### 3.2 家人一侧（三种情况都只要一步）

1. **还没装 Iris**：点链接 → 下载页，自动识别这是邀请，下载按钮旁写"安装后会自动连上 Wilhelm"。装好、第一次打开 Iris 时，快速设定里多一步：「Wilhelm 想帮你照看这台电脑，同意吗？」→「同意」。
   - 怎么做到"装好就认得邀请"：下载页把邀请写进浏览器下载的文件名做不到，所以用**口令**：家人在微信里复制那段话（或者顾问现场复制），Iris 第一次打开时读一下剪贴板，**只认 `✦IRIS:` 开头的这一种格式**，别的内容一概不看、不存。
2. **已经装了 Iris**：在微信里复制那段话 → 打开 Iris → 弹出「Wilhelm 想帮你照看这台电脑」→「同意」。
3. **顾问就在旁边**：顾问在家人电脑上打开自己发的那条微信，复制，打开 Iris，点同意。

为什么用"口令"而不是只用链接：
- 微信电脑版用内置浏览器打开链接，内置浏览器通常不允许直接唤起桌面程序，链接点了可能没反应；"复制一段话"在微信里一定能做到。
- "复制口令、打开 App 自动识别"是国内用户非常熟悉的方式（购物 App 的分享口令就是这样）。
- 链接仍然保留：在系统浏览器里打开时，能直接唤起 Iris（需要登记 `iris://` 链接协议，第一次运行时征得同意后写在当前用户的注册表里，卸载时删除）。

**剪贴板的边界**（写进隐私政策）：只在 Iris 窗口被打开或切到前台时读一次；只认 `✦IRIS:` 格式；认出来以后立刻从内存里丢掉原文，只留下解析出的邀请；设置里可以关掉"自动识别邀请"。

### 3.3 绑定之后

- 家人一侧：「设置 → 照看这台电脑的人」里能看到 Wilhelm，随时可以解除。
- 顾问一侧：「家人的电脑」里多了一张卡片"妈妈的笔记本 · 刚刚连上"。
- 一台电脑最多 3 位顾问（例如你和你兄弟）；一位顾问照看的电脑不限。

## 4. 之后的日常：不用想

```
家人体检 ──加密──▶ 中转信箱 ──▶ 顾问打开 Iris 时收到
顾问开处方 ──签名+加密──▶ 中转信箱 ──▶ 家人打开 Iris 时收到
家人执行 ──结果回执──▶ 中转信箱 ──▶ 顾问打开 Iris 时收到
```

- **同步报告**：家人每次体检完，报告自动加密上传给已绑定的顾问。默认是**打码后的报告**（和发给 AI 的一样，用户名、电脑名、邮箱换成占位符）；家人可以在设置里改成"让顾问看到完整报告"。
- **顾问看报告**：「家人的电脑」→ 点开一台 → 和看自己的报告完全一样的界面，只是标着"妈妈的笔记本 · 3 小时前体检"。
- **开处方**：顾问在家人的报告里勾选结论（和平时加入处理清单一样），可以写一句话，点「发给妈妈」。处方里只有"哪几条结论、选了哪些选项、一句话"，**没有任何命令或路径**。
- **家人执行**：家人下次打开 Iris，概览页最上面是一张卡片：
  > **Wilhelm 帮你准备好了 3 项**　"妈，先把缓存清了，那个 QuickVPN 卸了吧"
  > 「看看是什么」「一键处理」
  点「一键处理」→ Iris 用**家人电脑现在的状态**重新核对每一项（按规则和对象对应，和"带到下一次体检的清单"同一套逻辑），已经不存在的项自动略过 → 弹家人自己的 Windows 确认框 → 执行、重新检测 → 结果回执自动发给顾问。
- **不常驻**：报告只在家人体检后上传；处方只在家人打开 Iris 时去取；回执只在顾问打开 Iris 时去取。没有任何后台程序。

## 5. 轻量社交

| 元素 | 怎么做 |
| --- | --- |
| **留言** | 每份处方、每张回执都能带一句话；家人也可以主动发「电脑又卡了」（附上最新一次体检）。一条留言最多 200 字，只有文字 |
| **感谢卡** | 处理完成后家人那边出现「谢谢 Wilhelm」按钮，点一下顾问那边收到一张卡片："妈妈说谢谢 · C 盘多出了 12 GB"。顾问可以把卡片存成图片，发朋友圈（内容去隐私） |
| **帮忙记录** | 每台家人的电脑一条时间线：体检、处方、结果、留言、健康分走势。顾问一眼看到"上次是 10 天前帮她清的缓存" |
| **状态小标** | 「家人的电脑」列表上每台电脑一个状态：一切正常 / 有 2 项建议 / 很久没体检了（超过 30 天） |

不做：聊天、群组、点赞排行、任何陌生人之间的互动。

## 6. 安全

| 风险 | 对策 |
| --- | --- |
| 服务器被入侵、被偷看 | 端到端加密：每台 Iris 第一次用到这个功能时生成自己的钥匙对（Windows 自带的 DPAPI 保护，只有本机本账户能读）；报告和处方都用对方的公钥加密，服务器只存密文 |
| 有人冒充顾问发处方 | 处方用顾问的私钥签名，家人的 Iris 只认绑定时记下的那个公钥 |
| 邀请被别人截走 | 邀请 7 天过期、只能用一次；家人一侧必须看到顾问的名字并点「同意」；绑定成功后顾问一侧会看到"妈妈的笔记本已连上"，如果不是自己发的邀请可以立即移除 |
| 骗子拿 Iris 骗老人 | 处方里只有结论编号和选项，没有命令和路径；能做的操作和家人自己点的完全一样，全部来自操作库、受红线约束；到了家人电脑上要重新核对、弹确认框；**狂暴模式不能远程开启**；能撤销的步骤都能一键撤销 |
| 顾问看到不该看的 | 默认只看打码后的报告；家人随时可以解除绑定，解除后服务器上的数据立即删除 |
| 钥匙丢了（重装系统、换电脑） | 顾问一侧：「导出顾问身份」存成一个加密文件，新电脑上导入；没导出的话，请家人重新接受一次邀请即可（家人一侧只需要再点一次同意）|

## 7. 服务器（放在私有仓库 iris-cloud，和反馈服务在一起）

- **中转信箱**：每台 Iris 一个信箱，编号是它公钥的哈希。
  - `POST /v1/box/{id}`：放进一个密文（≤ 2 MB），任何持有邀请或已绑定的人都能放，带签名
  - `GET /v1/box/{id}?since=…`：取出新密文，**只有信箱主人**能取（用私钥签名证明）
  - `DELETE /v1/box/{id}/{msg}`：取到后删除
- 密文最多保留 30 天（对象存储的生命周期规则自动删除）；解除绑定时立即删除相关密文。
- 限流：每个信箱每天最多 100 条，防止滥用。
- 服务器记得的只有：信箱编号、密文大小、时间、来源 IP（访问日志，7 天删除）。
- 成本：一份打码报告压缩后约 50～200 KB，几十台电脑一个月不到 1 元。

## 8. 隐私政策要加的内容

- 「家人的电脑」是可选功能，不绑定就不会上传任何东西
- 绑定后会同步什么（默认打码的体检报告、处方、回执、留言），发给谁（只给你同意的人），服务器看不到内容
- 剪贴板只认 Iris 邀请口令
- `iris://` 链接协议的登记和删除

## 9. 界面一览

- **概览页**：家人一侧出现"顾问帮你准备好了"的卡片；顾问一侧出现"家人的电脑"摘要（有几台需要看）
- **新的一页「家人的电脑」**（左侧导航，只有添加过才显示）：电脑列表 → 某台电脑（报告 + 时间线 + 开处方）
- **设置**：照看这台电脑的人、自动识别邀请口令、同步完整报告还是打码报告、导出 / 导入顾问身份

## 10. 分几步做

1. 钥匙对和加密封装（本机），中转信箱接口（服务器），单元测试
2. 邀请：生成、口令识别、链接协议、绑定确认
3. 报告同步和「家人的电脑」页（只读）
4. 处方：开处方、家人一侧重新核对和执行、回执
5. 留言、感谢卡、帮忙记录、状态小标
6. 隐私政策、内测说明、文档

## 11. 需要作者决定的

1. **剪贴板识别口令**：能接受吗？（我推荐：能。这是在微信里最顺手的方式，而且只认一种格式、可以关掉）
2. **顾问默认看到打码报告**，家人可以改成完整报告：同意吗？
3. **顾问收不到即时提醒**（不常驻、也没有手机端）：家人求助时，顾问要等下次打开 Iris 才看到。以后如果做微信小程序，可以补上提醒。现在这样可以吗？
4. **一台电脑最多 3 位顾问**：够吗？
5. 这个功能需要服务器地址，**没写服务器地址的构建里不出现**（和内测反馈一样）：同意吗？
