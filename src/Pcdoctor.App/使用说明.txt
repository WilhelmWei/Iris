Iris
====

电脑用久了，又热、又卡、又慢？试试 Iris。定位，动手，解决。

一个不常驻、不弹窗、不捆绑的电脑体检工具：
每个结论都告诉你看到了什么、为什么这么判断；处理前说清代价，处理后重新检测确认，每一步都能撤销。

怎么用
------
1. 把压缩包完整解压到任意文件夹（不要在压缩包里直接双击）
2. 双击 Iris.exe
   如果 Windows 提示"Windows 已保护你的电脑"，点"更多信息"→"仍要运行"
   （这一版还没有代码签名证书，所以 Windows 不认识发布者）
3. 第一次打开有一个快速设定（隐私说明、内测反馈、AI、外观；AI 和外观可以跳过）
4. 点"开始体检"。会弹出一次管理员确认，用来读取驱动和系统日志；点"否"也能体检，只是结果不完整
5. 大约 2 分钟后自动打开报告。点开每一条结论看详情，想处理的点"加入处理清单"，再在底部的处理清单里"检查并执行"

两种研判方式
------------
· 纯规则（默认）：完全不联网，按固定规则和知识库判断，拿不准的会列成问题问你
· AI 研判：在快速设定或"设置"里填一个 API Key（DeepSeek、Kimi、通义千问或任何 OpenAI 兼容接口）。
  AI 会逐项解释"这是什么、为什么这么判断"。发送前会把用户名、计算机名、邮箱换成占位符，
  只发送需要判断的项目（程序名、路径、厂商、签名状态等），不包含文档、照片、聊天记录、浏览记录、密码。
  发出去的全部内容保存在数据文件夹里（evidence.json），随时可以查看。
  注意：AI 功能会调用第三方 AI 厂商的接口，可能由厂商收取费用（一次体检通常只要几分钱）

安全承诺
--------
· 体检只读：不改动任何东西
· 处理由你决定：只执行你加入处理清单的项目，执行前列出"会改什么、代价、怎么撤销"
· 每一步都重新检测：没生效的自动恢复原状；做完的在"还原"里一键撤销
· 不碰的东西：不关 Defender / 防火墙 / UAC，不改 Windows 自带服务，不停正在运行的驱动，
  不永久删除你的文件（清理缓存只移到回收站），不清空回收站
· 不常驻：关掉窗口就完全退出；需要管理员权限时临时启动一个辅助程序，做完就退出
· 查病毒交给 Windows 自带的 Microsoft Defender，我们只读取它的结果，不修改任何安全设置

数据放在哪
----------
全部在 %LOCALAPPDATA%\pcdoctor（设置页有"打开数据文件夹"按钮）：
体检报告、操作记录、设置（API Key 用 Windows 自带的 DPAPI 加密，只有你的账户能解开）。
需要管理员权限的操作，记录和备份放在 C:\Program Files\pcdoctor-data（只有管理员能改，防止被其他程序篡改后借"撤销"做坏事）。
删除这两个文件夹和 Iris.exe 就是完全卸载。

朋友的电脑
----------
朋友可以用"远程体检包"只做采集，把 pcdoctor-report-时间.json 发给你；
你在首页点"打开朋友发来的报告…"研判。别人电脑的报告只能查看，不能在你的电脑上执行。
